# Security

This repository is prompt-only by default.

- It does not need API keys, OAuth tokens, cookies, browser profiles, or Keychain access.
- Do not add credential-reading code or undocumented service endpoints.
- Do not commit generated files containing customer, account, or local-path data.
- Report a vulnerability through GitHub private vulnerability reporting when available.

If you connect these prompts to another renderer, follow that renderer's official authentication and security documentation. Never paste credentials into prompts, logs, screenshots, or issue reports.
